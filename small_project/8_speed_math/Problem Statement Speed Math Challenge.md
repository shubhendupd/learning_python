

Build a command-line math quiz game that tests how quickly a user can solve 10 random arithmetic problems.

#### Requirements:

1. **Generate Problems**: Create 10 problems using random integers between 3 and 12, combined with random operators (`+`, `-`, `*`).
    
2. **Input Loop**: For each problem, keep asking the same question until the user enters the correct answer. Track the number of wrong attempts.
    
3. **Timer**: Start a timer when the user presses Enter to begin. Stop it when all 10 problems are answered correctly. Display the total time taken (in seconds).
    
4. **Feedback**: Show a completion message with the final time.
